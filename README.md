# Закрывающий тег

Проект по вёрстке с восемью карточками о прохождении курса. Карточкам можно ставить лайки, а кнопка «Сохранить на память» открывает диалог.

Для запуска откройте сайт через локальный HTTP-сервер, например запустите `python3 -m http.server` из корня проекта и перейдите на [localhost:8000](http://localhost:8000).
